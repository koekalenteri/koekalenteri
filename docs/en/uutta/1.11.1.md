## New

- A multi-day class's start numbers are entered and published one day at a time: Friday's draw can
  be public while Saturday's is still to come.

## Fixed

- A start number is the dog's own in the whole trial, in every class and on every day; two dogs
  cannot hold the same number.
- The secretary's event list stays in date order after a trial is saved.
- In the statistics the starters and the reserve list count only from trials already held.

## Faster

- The statistics' nightly run does far less work: it counts the dogs, handlers and trials without a
  row for each, and clears out old figures in batches.
