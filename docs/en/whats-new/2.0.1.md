## Fixed

### For the participant

- The calendar's search shows the trials' current details also when the date range is widened to
  trials looked at earlier, or when the phone's clock runs ahead. Before, filtering for trials with
  results, for example, could leave trials out, because their results were missing from the old copy
  kept in memory.

### For the trial secretary

- The event list is refreshed after signing in again. Before, the list could stay outdated or empty
  if a single update from another user had already reached it.

### For the administrator

- The message template editor no longer warns about an unknown field in the opening of an
  `{{#each ...}}` block, nor about the name in the `as |r|` form.
